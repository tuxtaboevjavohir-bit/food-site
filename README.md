# Food house — штаб ИИ-агентов

Программа для кафе Food house: вы даёте задачу, **директор** распределяет её между **маркетологом**, **финансистом** и **бухгалтером**. Агенты ходят по офису, работают и приносят результат, а директор сводит итог в план действий. Все читают **память заведения** и **меню**.

## Запуск

1. Установите Python 3.10+ (на Windows при установке отметьте «Add Python to PATH»).
2. Windows: дважды нажмите `start_windows.bat`.
   Mac/Linux: `bash start_mac_linux.sh`.
3. Откройте http://localhost:8000.

Без ключа программа работает в **демо-режиме** с ненастоящими ответами. Чтобы агенты отвечали по-настоящему:
откройте файл `.env`, впишите `ANTHROPIC_API_KEY=ваш_ключ` (ключ берётся на console.anthropic.com) и перезапустите программу.

## Вкладки

- **Штаб**: офис с анимацией, поле для задачи, ответы агентов и итог директора.
- **Меню**: загрузка фото меню из галереи, файлом или с камеры. Меню распознаётся и сохраняется, агенты учитывают его в расчётах.
- **Память**: факты о заведении (часы работы, средний чек, поставщики, цели).
- **История**: прошлые задачи и итоги.

## Файлы

| Файл | Что внутри |
|---|---|
| `app.py` | веб-сервер и API |
| `agents.py` | агенты, их роли и распознавание меню |
| `memory.py` | база SQLite `foodhouse.db` |
| `static/index.html` | страница с анимацией |

Как добавить нового агента (например, шеф-повара): допишите его в `AGENTS` и `SPECIALISTS` в `agents.py`, а место в офисе добавьте в `SEATS` в `index.html`.
